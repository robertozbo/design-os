# Convidar Aluno Specification

## Overview
Convite para o aluno baixar o app e se vincular à personal (código + link). Fonte: professional.invites e professional.referrals.

## User Flows
- Copiar código ou link
- Compartilhar pelo WhatsApp ou pela folha de compartilhamento do sistema
- Ver convites enviados e reenviar os expirados

## UI Requirements
- Cartão com código grande em mono, link e QR
- Prévia da mensagem padrão
- Botões WhatsApp e Compartilhar
- Lista de convites com status (enviado, aceito, expirado)

## Configuration
- shell: true
