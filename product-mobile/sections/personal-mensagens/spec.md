# Mensagens do Personal Specification

## Overview
Caixa de conversas com os alunos dentro do Nymos (substitui o WhatsApp para assunto de treino, com histórico ligado à ficha). Fonte: professional.messages.

## User Flows
- Ver conversas por mais recente, com não lidas no topo
- Toca → conversa
- Nova mensagem → escolhe aluno

## UI Requirements
- Busca
- Linha com avatar, nome, prévia, hora e contador de não lidas
- Ícone quando a mensagem tem vídeo ou treino anexado

## Configuration
- shell: true
