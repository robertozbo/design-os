# Programas de Treino Specification

## Overview
Periodização por aluno: programa com fases (mesociclos), datas e progresso. No mobile o personal acompanha e ajusta; montar um programa do zero continua mais confortável no web.

## User Flows
- Ver programas ativos com fase atual
- Toca → detalhe da fase e treinos ligados
- Criar programa

## UI Requirements
- Card por programa com aluno, datas e barra de progresso
- Linha do tempo das fases (concluída, atual, próxima)
