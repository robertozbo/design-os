# Alunos do Personal Specification

## Overview
Aba Alunos do app Personal. Lista todos os alunos vinculados com status, adesão da semana e treino atual; filtros rápidos e busca. Fonte: professional.patients + professional.activities.

## User Flows
- Busca por nome
- Filtra por Todos / Precisam de atenção / Ativos / Pausados / Convidados
- Toca no aluno → ficha
- Botão Convidar → tela de convite

## UI Requirements
- Busca no topo
- Filtros em pílulas com contagem
- Linha com avatar, nome, objetivo, treino atual, barra de adesão e alerta
- Cores de adesão: verde ≥75, amarelo 50–74, vermelho <50
