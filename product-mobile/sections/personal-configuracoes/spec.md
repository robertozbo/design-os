# Configurações do Personal Specification

## Overview
Preferências da personal no app: avisos push, regras de atendimento (horários, duração, ciclo de reavaliação, pedidos públicos) e app (idioma, Face ID, privacidade). Fonte: professional.preferences, professional.availability.

## User Flows
- Liga/desliga avisos
- Abre horários de atendimento
- Ajusta ciclo de reavaliação
- Privacidade e dados

## UI Requirements
- Grupos com label mono
- Itens com toggle verde ou valor + seta
- Versão do app no rodapé
