# Perfil Profissional Specification

## Overview
Perfil profissional da personal: CREF, bio, especialidades, locais de atendimento e modalidades. É o que aparece na página pública de agendamento. Fonte: professional.core / professional.directory.

## User Flows
- Ver perfil
- Editar dados
- Ver página pública

## UI Requirements
- Avatar grande com selo CREF
- Bio
- Especialidades em pílulas
- Locais e modalidades
- Link público com botão
