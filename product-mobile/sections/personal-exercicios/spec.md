# Biblioteca de Exercícios Specification

## Overview
Biblioteca curada (~200 exercícios com vídeo) + exercícios criados pelo personal. Usada para montar treinos e adicionar exercício a um dia do template.

## User Flows
- Busca por nome
- Filtra por grupo muscular
- Toca no exercício → adiciona ao treino (quando aberto a partir do treino) ou abre detalhe com vídeo
- Criar exercício personalizado

## UI Requirements
- Busca + filtros em pílulas
- Linha com miniatura (ícone de play quando tem vídeo), nome, grupo e equipamento
- Selo Meu nos personalizados
- Botão Criar exercício
