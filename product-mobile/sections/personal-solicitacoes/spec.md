# Solicitações de Agendamento Specification

## Overview
Pedidos de agendamento e remarcação feitos pelos alunos (ou por novos interessados via link público). O personal aceita, sugere outro horário ou recusa. Fonte: professional.appointments (requests).

## User Flows
- Ver pendentes com mensagem do aluno
- Aceitar → entra na agenda e avisa o aluno
- Sugerir outro horário
- Recusar
- Ver respondidas

## UI Requirements
- Card por pedido com avatar, selo Novo aluno, horário pedido e mensagem
- Três ações: Aceitar (verde), Sugerir, Recusar
- Lista de respondidas com resultado
